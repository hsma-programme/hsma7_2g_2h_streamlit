Getting started with streamlit

How to create and run a Streamlit app

  1. Install Streamlit.

    pip install streamlit
  1. Create a Python script (e.g., app.py).

  1. Import Streamlit at the top of your script:

    import streamlit as st

  1. Run your app from the terminal:

    streamlit run app.py

What can we put in a Streamlit app?

Let’s start with text: a title, a header and a subheader.

Widgets: st.radio

Widgets are interactive controls that let users provide input.

For example, st.radio lets users choose one option from a list.

Set the prompt with label, the choices with options, and the starting position with index (0 selects the first option).

import streamlit as st

st.pills(
    label="Choose an option",
    options=["A", "B", "C"],
    default="A",
)

Widgets: st.pills and st.segmented_control

These display the choices as buttons rather than a radio list.

Use label and options as before, but set the starting choice with default (e.g., "A") rather than its position.

import streamlit as st

st.segmented_control(
    label="Choose an option",
    options=["A", "B", "C"],
    default="A",
)

st.radio(
    label="Choose an option",
    options=["A", "B", "C"],
    index=0,
)

Drag a slider or type a number to set a numeric value.

Set the prompt with label, the limits with min_value and max_value, the starting value with value, and the increment with step.

Accessing the chosen value

Access the chosen value through a variable or st.session_state.


To assign the widget’s return value to a variable:

import streamlit as st

chosen_value = st.slider(
    label="Pick a number", 
    min_value=0,
    max_value=10,
    value=2,
    step=1
)

st.write(f"Chosen number: {chosen_value}")

Accessing the chosen value

Alternatively, give the widget a key to access its value through st.session_state.

import streamlit as st

st.slider(
    label="Pick a number", 
    min_value=0,
    max_value=10,
    value=2,
    step=1,
    key="chosen_value"
)

st.write(f"Chosen number: {st.session_state.chosen_value}")

Session state

Session state keeps track of values between script re-runs, like a dictionary for the current user’s session.


For our slider with a key:

  1. The user chooses a new inter-arrival time.

  2. Streamlit updates the value in st.session_state.

  3. The script reruns, reading and using the updated value.

import math
import numpy as np
import pandas as pd
import simpy
from scipy import stats

# stlite requires imports without dotted names
from sim_tools import distributions
Exponential = distributions.Exponential
Lognormal = distributions.Lognormal


class Patient:
    def __init__(self, p_id):
        self.id = p_id

        self.q_time_nurse = pd.NA


class Param:
    def __init__(
        self,
        mean_patient_inter=5,
        mean_nurse_consult_time=6,
        sd_nurse_consult_time=1,
        num_nurses=1,
        sim_duration=120,
        num_replications=5,
        nurse_cost_per_hour=30,  # NEW
    ):
        self.mean_patient_inter = mean_patient_inter
        self.mean_nurse_consult_time = mean_nurse_consult_time
        self.sd_nurse_consult_time = sd_nurse_consult_time
        self.num_nurses = num_nurses
        self.sim_duration = sim_duration
        self.num_replications = num_replications
        self.nurse_cost_per_hour = nurse_cost_per_hour  # NEW


class Model:
    def __init__(self, param, replication_id):
        self.param = param
        self.replication_id = replication_id
        self.env = simpy.Environment()
        self.patient_counter = 0
        self.nurse = simpy.Resource(self.env, capacity=self.param.num_nurses)

        ss = np.random.SeedSequence(self.replication_id)
        seeds = ss.spawn(2)
        self.patient_inter_dist = Exponential(
            mean=self.param.mean_patient_inter, random_seed=seeds[0]
        )
        self.nurse_consult_time_dist = Lognormal(
            mean=self.param.mean_nurse_consult_time,
            stdev=self.param.sd_nurse_consult_time,
            random_seed=seeds[1],
        )

        self.list_of_patients = []
        self.mean_q_time_nurse = pd.NA
        self.sd_q_time_nurse = pd.NA
        self.perc_90_q_time_nurse = pd.NA

    def generator_patient_arrivals(self):
        while True:
            self.patient_counter += 1
            p = Patient(self.patient_counter)
            self.list_of_patients.append(p)
            self.env.process(self.attend_clinic(p))
            sampled_inter = self.patient_inter_dist.sample()
            yield self.env.timeout(sampled_inter)

    def attend_clinic(self, patient):
        start_q_nurse = self.env.now

        with self.nurse.request() as req:
            yield req
            end_q_nurse = self.env.now
            patient.q_time_nurse = end_q_nurse - start_q_nurse
            sampled_nurse_act_time = self.nurse_consult_time_dist.sample()
            yield self.env.timeout(sampled_nurse_act_time)

    def run_model(self):
        self.env.process(self.generator_patient_arrivals())
        self.env.run(until=self.param.sim_duration)

    def convert_entity_list_to_dataframe(self, entity_list):
        entity_dateframe = pd.DataFrame(entity.__dict__ for entity in entity_list)

        return entity_dateframe

    def calculate_run_results(self, entity_dataframe):
        self.mean_q_time_nurse = entity_dataframe["q_time_nurse"].mean()
        self.sd_q_time_nurse = entity_dataframe["q_time_nurse"].std()
        self.perc_90_q_time_nurse = entity_dataframe["q_time_nurse"].quantile(0.9)


class Trial:
    def __init__(self, param):
        self.param = param
        self.list_of_simulation_replications = []
        self.trial_mean_q_time_nurse = pd.NA
        self.trial_sd_q_time_nurse = pd.NA
        self.trial_perc_90_q_time_nurse = pd.NA
        self.ci_lower_q_time_nurse = pd.NA
        self.ci_upper_q_time_nurse = pd.NA
        self.se_q_time_nurse = pd.NA

    def run_trial(self):
        for replication_id in range(self.param.num_replications):
            model_replication = Model(self.param, replication_id)
            model_replication.run_model()
            patient_df = model_replication.convert_entity_list_to_dataframe(
                model_replication.list_of_patients
            )
            model_replication.calculate_run_results(patient_df)
            self.list_of_simulation_replications.append(model_replication)

    def calculate_trial_results(self):
        self.replication_df = pd.DataFrame(
            replication.__dict__ for replication in self.list_of_simulation_replications
        )

        self.trial_mean_q_time_nurse = self.replication_df["mean_q_time_nurse"].mean()

        self.trial_sd_q_time_nurse = self.replication_df["mean_q_time_nurse"].std()

        self.trial_perc_90_q_time_nurse = self.replication_df[
            "mean_q_time_nurse"
        ].quantile(0.9)

        self.se_q_time_nurse = self.trial_sd_q_time_nurse / math.sqrt(
            self.param.num_replications
        )

        t = stats.t.ppf(0.975, df=self.param.num_replications - 1)

        self.ci_lower_q_time_nurse = self.trial_mean_q_time_nurse - (
            t * self.se_q_time_nurse
        )

        self.ci_upper_q_time_nurse = self.trial_mean_q_time_nurse + (
            t * self.se_q_time_nurse
        )

        # NEW
        self.total_nurse_cost = (
            self.param.num_nurses
            * self.param.sim_duration
            / 60
            * self.param.nurse_cost_per_hour
        )


base_case_params = Param()
base_case_trial = Trial(base_case_params)
base_case_trial.run_trial()
base_case_trial.calculate_trial_results()
print ("BASE CASE TRIAL RESULTS")
print ("-----------------------")

Streamlit app

We’ll build a simple app in four steps:

  1. Create the app script.

  2. Get inputs from the user.

  3. Run the model using those inputs.

  4. Display the results.

Create the app script

Create app.py in the same folder as model.py.

It should contain these imports:

import plotly.express as px
import streamlit as st

from model import Param, Trial
  • plotly.express: chart the results.
  • streamlit: build the interface.
  • Param and Trial: configure and run the model. Here, model refers to model.py in the same folder. The import makes Param and Trial available in our app.

Why two Python files?

  • Run and test the model independently of the app.
  • Avoid redefining model classes each time Streamlit reruns.

When should the model run?

Changing an input reruns the script, but we only want to run the simulation when the user is ready.

st.button() adds a button. Clicking it re-runs the script and returns True for that run, so the indented simulation code executes.

if st.button("Run simulation", type="primary"):
    params = Param(
        mean_patient_inter=st.session_state.mean_patient_inter,
        mean_nurse_consult_time=st.session_state.mean_nurse_consult_time,
        sd_nurse_consult_time=st.session_state.sd_nurse_consult_time,

Multipage apps


So far, we have created a single page app.


Now let’s turn it into a multipage app by adding a homepage. This should:

  • Introduce the model and its uses.
  • Explain how to use the app.
  • Credit the authors.

Organising our multipage app

  1. Rename our existing app.py to simulation.py.
  2. Create home.py for our homepage.
  3. Create app.py as the main entry point. In app.py, we define each page using st.Page() and provide these as a list to st.navigation() which we then run().

app.py:

import streamlit as st

# Define pages and their order
pg = st.navigation(
    [
        st.Page("home.py", title="Home"),
        st.Page("simulation.py", title="Run simulation"),
    ]
)
pg.run()
